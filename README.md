# 嵌入式 C 语言代码覆盖分析与静态分析套件 (C++ Qt)

这是一个面向车载电子、工业控制、航空航天航电等安全关键领域的工业级软件工程工具，专注于嵌入式 C 语言的前置**静态代码分析**、**代码度量 (LOC/语句数/分支数/注释率/MCDC数/扇入扇出/函数与调用深度)**、**函数独立路径提取与图元/源码联动绿色着色探索**、**静态堆栈与二进制最大调用栈深度分析 (Stack Analyzer)**、**源码级探针插桩与覆盖率分析**、**测试覆盖统计大表与多维图表 (柱状图/折线图/饼图)**、**多工况 Python 激励注入 (内置环境检测与选择)**、**内置纯只读报告预览器 (HTML/PDF/Word/JSON)**、**全周期运行日志持久化系统**以及**企业级项目隔离目录规范**。

## 🌟 核心特性与系统架构 (v2.7.0 企业工程版)

### 1. 启动未打开工程安全互斥与欢迎向导
* **纯净启动与未打开工程状态保护**：软件启动时默认未载入任何项目，左侧工程树为空，中央**仅显示欢迎向导卡片**与**底部系统实时运行日志**，代码编辑器、静态分析工作台、拓扑图、堆栈分析器及右侧覆盖度量/激励工作台处于隐藏状态，避免无效计算或误操作。
* **业务菜单与工具栏互斥保护**：未打开工程时，菜单栏中所有业务功能项（保存工程/关闭工程/保存文件/导出报告/静态分析/代码插桩/堆栈分析/仿真运行/激励执行等）**全面禁用**；顶部主控制工具栏**仅显示「工程管理中心」与「打开工程」**两个入口，其余功能按钮、分割线及文件切换器全部隐藏。
* **打开工程自动就绪**：通过欢迎向导、工程中心或菜单打开项目后，欢迎向导自动关闭，主工作区各视窗自动展开，全部功能按钮与工具栏恢复启用。
* **最近工程双击直达**：欢迎向导中展示工程名称、目标硬件芯片/架构、绝对路径及就绪状态，界面精简整洁，**双击任意历史工程即可瞬间载入分析现场**。

### 2. 系统外观明暗模式自动感知与主题自适应
* **操作系统明暗模式自动检测**：启动时自动读取 Windows 注册表和系统配置，检测当前系统处于深色还是浅色模式：
  - 浅色模式系统：默认自动启用 **「现代清新白」** 主题；
  - 深色模式系统：默认自动启用 **「深色科技风」** 主题。
* **全局控件像素级主题适配**：对所有对话框、卡片、表格、树形控件及编辑框进行统一色彩适配，杜绝亮暗混杂；全面消除所有功能按钮被点击时的外围白色焦点框线。
* **四套现代主题自由切换**：支持深色科技风 (Catppuccin)、现代清新白 (Modern Light)、Solarized 暗夜与 Monokai Pro。

### 3. 严格规范的项目目录隔离体系
* 强制遵循工业级目录隔离架构，每个项目拥有专属同名目录及独立的 4 大功能子文件夹：
  - `<ProjectName>/<ProjectName>.covproj`：工程元数据核心配置文件；
  - `Source/`：专属嵌入式 C/C++ 源文件 (*.c, *.cpp)；
  - `Header/`：专属头文件 (*.h)；
  - `Script/`：专属 Python 激励测试与注入脚本 (*.py)；
  - `Report/`：专属导出的质量与覆盖分析报告文件 (*.html, *.docx, *.pdf, *.json)；
* 彻底杜绝不同工程间源文件与报告制品的交叉混杂。

### 4. 静态堆栈与二进制调用深度分析器 (Static Stack Analyzer - 零第三方外部 exe 依赖)
* **安全标准背景**：面向 **ISO 26262 ASIL-D** 与 **DO-178C Level A** 等高安全性标准，提供完全静态、无插装运行开销的二进制最大调用栈消耗求解与调用链路可视化。
* **纯内置原生解析引擎 (Zero External Executable)**：
  - 核心采用**纯 C++ 内置 ELF/PE 解析器与指令解码器**，完全不需要依赖任何外部第三方 `.exe` 程序（如 `objdump.exe`）；
  - 直接内存解析 32位/64位 ELF (`.elf`, `.o`, `.axf`) 及 Windows PE/COFF (`.exe`, `.obj`) 符号表、节区、代码段与导出函数；
  - 结合内置 GCC `-fstack-usage` 生成的 `.su` 静态栈用量文件解析器；若无 `.su` 文件，由内置指令解码器扫描机器指令 (`push`, `sub esp/rsp`, `stp`, `str` 等) 及 AST 源码调用拓扑自动推导局部栈帧。
* **DFS 全局最大调用栈 (Worst-Case Peak Stack) 求解**：
  - 基于深度优先搜索算法遍历有向无环图 (DAG)，自动计算出系统最坏情况下的最大栈深度峰值与完整调用链路；
  - 严格呈现 8 列函数指标：序号、函数名称、所在源码文件、行号、自身栈大小 (B)、最大调用栈 (B)、调用类型、MISRA 17.2 递归风险；
  - 点击任一行函数即可即时查看对应反汇编汇编代码片段。

### 5. 静态分析高级度量指标与路径探索工作台
* **全维度函数度量指标扩展**：
  - 全面支持计算并展示嵌入式关键质量指标：**扇入数 (Fan-In)**、**扇出数 (Fan-Out)**、**函数嵌套深度 (Function Depth)** 与 **调用深度 (Call Depth)**；
  - **选项卡 1【函数度量总览】**：头部 KPI 看板综合展示语句数、分支数、注释率、MC/DC 判定数、最高圈复杂度与缺陷数；总览表格规范化呈现 11 列核心度量：**序号、函数名称、源码位置、语句数、分支数、圈复杂度、扇入数、扇出数、函数深度、调用深度、MC/DC数**。
* **选项卡 2【函数控制流与路径探索】**：
  - 函数全量线性独立基路径列表，选中某条路径时，Graphviz 控制流图中**执行边自动着色加粗（翠绿高亮 #10b981，2.8px），执行节点边框加粗着色（翠绿高亮 #10b981）**；
  - 右侧源代码查看框使用默认高亮初始化渲染，当路径选定时，**被该路径实际执行的代码行字体变为高亮绿色（#10b981 + 加粗），背景附带柔和浅翠绿高亮**，直观清晰呈现执行轨迹。

### 6. 独立测试覆盖分析工作台 (Test Coverage Studio)
* **独立功能入口与专属矢量图标**：
  - 拥有专属的测试覆盖分析矢量图标 (`coverage_analysis.svg`)，与覆盖仿真运行图标清晰区分；
  - 支持快捷键 `F8`、菜单栏「分析 -> 测试覆盖分析」及主控制工具栏一键进入；
* **科学精准的覆盖率统计与探针算法 (严禁覆盖变量定义与注释)**：
  - **严密的多文件覆盖报告隔离机制**：为工程内的每个源文件单独生成并持久化隔离的覆盖报告，杜绝在切换文件时发生行号错位，彻底解决“执行行被误标为分支、注释行被误标为分支”的问题；
  - **严格注释与非执行行过滤**：单行注释 (`//`)、块注释 (`/* ... */`)、前导星号注释行及预编译宏指令行在插桩和着色时被强制过滤，严禁插入探针，严禁在激励注入时被误记为覆盖或分支；
  - **分支判定关键词严密核验**：仅当代码行真正包含条件控制关键字 (`if`, `switch`, `while`, `for`, `?`) 时才允许被标记为分支判定行；普通执行语句行仅允许标记为绿色已覆盖或红色未覆盖，绝不误标为黄色部分分支；
  - 变量声明（如 `int a;`、`float v;`、`static MotorState st;` 等）严格作为非执行代码过滤，不插入探针；
  - 函数覆盖、分支覆盖与语句覆盖实时自愈同步，杜绝“函数总数为 0”的问题，全面呈现精准分子分母徽标 `(已覆盖/总数)`；
* **代码覆盖页面显著图例 (Legend Chips)**：
  - 在代码覆盖视图顶部清晰呈现 4 种覆盖着色标准图例：
    - `🟩 已覆盖执行行 (Covered)`
    - `🟨 部分分支覆盖 (Partial)`
    - `🟥 未覆盖可执行行 (Uncovered)`
    - `⬜ 非执行/声明/注释 (Ignored)`
* **未覆盖代码快速审阅与显目光标位置指示器**：
  - 点击「上一未覆盖」与「下一未覆盖」按键时，系统自动精准跳转定位目标行；
  - **显目光标与行级选区**：目标行文本自动完整选中，编辑器自动获取焦点，并施加高对比度红色边框 (`OutlinePen`) 与强调背景，确保用户一眼锁定目标行；
  - **行号槽 (Gutter) 红色导向箭头**：在左侧行号区域同步绘制鲜红色指示箭头 `▶`，行号文字同步加粗加红；
  - **气泡辅助提示 (Tooltip)**：显示如 `📍 已定位至未覆盖/部分分支代码行: 第 X 行` 或 `🎉 恭喜！当前源文件中未检测到未覆盖行` 的即时状态气泡。
* **双模精准检索过滤面板（左侧）与全工程文件加载**：
  - 提供单选按钮自由切换「文件」或「函数」维度的覆盖清单；
  - 切换至「文件」模式时，自动载入当前工程下的全部源文件与头文件（*.c, *.h）；双击任意源文件自动加载该源码并着色覆盖状态，**自动跳转至「函数」模式并精准展示该源文件所属的所有函数列表**；
* **双选项卡专业分析视图（右侧底部切换）**：
  - **选项卡 1【覆盖统计】**：
    - 上半区严格呈现 9 列函数覆盖明细大表：**序号、函数名称、文件名、语句数、语句覆盖数、语句覆盖率(%)、分支数、分支覆盖数、分支覆盖率(%)**，双击任意行自动平滑切换至源码覆盖视图并定位对应函数；
    - 下半区提供多维交互图表：支持**鼠标右键弹出菜单**，自由切换 **📊 柱状分布图 (Bar Chart)**、**📈 趋势折线图 (Line Chart)** 与 **🥧 覆盖率饼图 (Pie Chart)** 三种风格；
  - **选项卡 2【代码覆盖】**：
    - 顶部源码下拉框支持自由切换查看当前工程中的任意源文件，切换文件后**同样自动联动切换到函数模式并刷新对应函数列表**；
    - 针对实际覆盖状态对源码执行多级色彩动态着色，行号槽（Gutter）显示覆盖状态指示图标，集成「上一处未覆盖 / 下一处未覆盖」快速审阅跳转按键。
* **只读控件双击防误触保护**：
  - 全面禁用了项目树、覆盖大表、函数列表、度量表、路径表、堆栈表及调用链树的双击行内编辑行为，彻底杜绝用户双击时误弹出文本编辑框。

### 7. Python 环境全盘检测与用户自由选择
* 点击「环境检测」按钮后，软件自动全面扫描当前计算机系统：
  1. 系统 `PATH` 环境变量中注册的 Python (`where.exe python`);
  2. 工作区与便携绿色嵌入式 Python 解释器 (`tools/python/python.exe`);
  3. Windows 用户目录与 `AppData/Local/Programs/Python`;
  4. 系统盘根目录 `C:\Python*` 与 `Program Files`;
  5. Anaconda / Miniconda 虚拟环境与 Conda Base。
* 弹出交互式选择对话框，呈现每个解释器的版本号与完整路径（如 `Python 3.10.11 - C:\...`），并提供手动浏览定位选项，由用户自由选择最适合的 Python 解释环境。

### 8. 项目激励脚本自动载入 (去除冗余预设模板)
* 激励配置处去除了非通用的预设模板下拉框，转为**动态读取当前项目 `Script/` 路径下的全部 Python 脚本**；
* 用户可以在下拉列表中自由切换选择项目测试脚本，系统自动同步脚本路径并载入编辑器，一键运行即可驱动仿真内核。

### 9. 纯内置报告浏览器 (零外部依赖，纯只读预览)
* 项目树「报告文件」节点自动遍历加载当前项目 `Report/` 目录下的所有格式报告：`*.html`, `*.htm`, `*.pdf`, `*.docx`, `*.doc`, `*.json`, `*.txt`；
* **双击任何报告文件均使用软件内置的 `ReportPreviewDialog` 打开**，严禁唤起外部三方软件；
* 预览对话框专用于审阅与只读查看，不展示导出控件，杜绝误触。

### 10. 项目树右键定位文件并选中 (Reveal in Explorer)
* 在项目树任意有效文件节点（工程根配置文件、C/C++ 源文件与头文件、Python 激励脚本、报告文件等）**右键均提供「📂 打开文件所在路径并选中」功能**；
* 点击后由软件直接唤起操作系统的资源管理器（Windows Explorer），直接打开目标文件所在目录，并**自动高亮选中该文件**，便于用户快速对文件进行备份、归档或外部调用。

### 11. 丰富的工业级真实示例工程与多工况激励脚本
* **工业级电机控制器代码 (Motor Controller)**：
  - 包含闭环 PID 控制器 (`pid_controller.c/.h`)，支持抗积分饱和、微分一阶滤波与死区限制；
  - 包含车载诊断故障冻结帧记录器 (`fault_recorder.c/.h`)，支持 DTC 故障码去重、时间戳与环境量快照；
  - 包含电机状态机、超温检测、欠压/过压保护、超速闭锁等真实业务逻辑。
* **多工况激励测试向量脚本**：
  - `normal_cruise.py`：模拟正常加速与稳态巡航闭环调节分支；
  - `overtemp_fault.py`：模拟绕组温度突破 105℃ 触发超温跳闸与 DTC 冻结帧记录分支；
  - `voltage_fluctuation.py`：模拟母线欠压 (< 2.2V) 与浪涌过压 (> 4.2V) 保护分支；
  - `emergency_estop.py`：模拟硬件级急停信号输入，触发紧急能耗制动分支。

## 🚀 软件运行指南

### 1. 运行图形化客户端 (GUI)
运行 `build/bin/` 目录下的可执行程序：
```powershell
.\build\bin\coverage_gui.exe
```

### 2. 运行命令行工具 (CLI)
```powershell
# 1. 针对嵌入式 C 源码执行静态质量检测
.\build\bin\coverage_cli.exe -f examples\motor_controller\Source\motor_controller.c --analyze

# 2. 导出原生 Word (.docx) 质量报告
.\build\bin\coverage_cli.exe -f examples\motor_controller\Source\motor_controller.c -w reports\motor_report.docx
```

## 🧭 操作指南速查表

| 快捷键 | 功能操作 | 说明 |
| :--- | :--- | :--- |
| **F1** | 软件使用说明书 | 打开内置文档查阅器，纯操作指南 |
| **Ctrl + P** | 呼出工程管理中心 | 新建、打开与管理工程，查看历史工程 |
| **Ctrl + Shift + N** | 创建全新工程 | 向导式创建规范隔离工程目录 |
| **Ctrl + Shift + O** | 打开已有工程 | 载入 `.covproj` 并唤醒工作区 |
| **Ctrl + Shift + S** | 保存当前工程 | 保存工程配置与文件清单 |
| **Ctrl + K** | 静态堆栈分析 | 呼出二进制静态堆栈与最大调用深度分析器 |
| **Ctrl + O** | 打开单个 C 源文件 | 导入单个源码文件至多标签编辑器 |
| **Ctrl + I** | 导入路径下所有文件 | 递归扫描目录并加入工程 |
| **Ctrl + S** | 保存当前代码文件 | 保存当前编辑器的源码 |
| **Ctrl + E** | 导出综合分析报告... | 导出 Word/PDF/HTML/JSON 报告 |
| **Ctrl + L** | 查看当前运行日志 | 打开当前会话的系统持久化运行日志文件 |
| **F5** | 执行静态分析 | 扫描安全隐患、圈复杂度与基路径 |
| **F6** | 执行源码探针插桩 | 在语句、分支及函数处插入微型探针 (忽略变量声明) |
| **F7** | 执行 Python 激励脚本 | 调用所选 Python 运行项目测试脚本 |
| **F8** | 测试覆盖分析工作台 | 打开独立覆盖分析视窗，审阅大表、图表与源码着色 |
| **Ctrl + F8** | 运行覆盖率仿真内核 | 驱动仿真内核计算覆盖率度量 |
